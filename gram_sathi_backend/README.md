# ग्रामसाथी (GramSathi) — AI Village Assistant

Full-stack Flask application with SQLite database, professional login/register authentication, weather API proxy, AI helper, agricultural guidance, government schemes, and emergency services.

## Setup Instructions:
1. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the Flask app:
   ```bash
   python app.py
   ```
3. Open in your browser:
   `http://127.0.0.1:5000`
